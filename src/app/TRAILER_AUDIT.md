# KinoLuma trailer audit

Проверка по статическим data-файлам показала, что большая часть каталога имеет пустое поле `trailerUrl`. Поэтому трейлеры нельзя надежно чинить только ручным добавлением ссылок в каждый объект.

Что сделано в этом патче:

- `lib/trailers.ts` теперь отправляет в `/api/tmdb/trailer` больше данных для поиска: `slug`, `tmdbId`, `imdbId`, `kinopoiskId`, `title`, `originalTitle`, `type`, `year`.
- `/api/tmdb/trailer` сначала проверяет ручные fallback-ссылки, потом ищет трейлер через TMDb API, потом пробует публичные страницы TMDb без API-ключа.
- Для фильмов/сериалов с `tmdbId` трейлер теперь может находиться даже если `TMDB_API_KEY`/`TMDB_ACCESS_TOKEN` не добавлены в `.env.local`.
- Для фильмов без `tmdbId`, но с названием и годом, API пробует найти карточку через TMDb search и уже оттуда достать YouTube-трейлер.

Лучший вариант для максимального покрытия: добавить в `.env.local` один из ключей:

```env
TMDB_ACCESS_TOKEN=...
# или
TMDB_API_KEY=...
```

Без ключа fallback тоже работает, но публичный HTML TMDb менее стабилен, чем официальный API.
